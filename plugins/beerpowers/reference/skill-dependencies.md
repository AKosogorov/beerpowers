# Скилы-зависимости

> Generic reference плагина. Читает team-lead при `/beerpowers:setup` (что вписать
> во frontmatter ролей) и `/beerpowers:doctor` (что проверить в сессии).

Скилы вне плагина, на которые опираются шаблоны ролей и charter. Наличие не гарантировано:
они ставятся отдельно и могут быть выключены. Поэтому правило одно — **во frontmatter
`skills:` роли и в колонку «Skills» charter вписывается только скил, видимый в текущей
сессии**: отсутствующий скил в поле `skills` ломает старт роли, а вызов `Skill` по имени
отказывает. Не найденный скил называется пользователю вместе с ролью, которая его теряет.

| Скил | Роли | Когда нужен | Если нет |
|---|---|---|---|
| `superpowers:test-driven-development` | `tester` | всегда | `tester` пишет тесты по своей секции без дисциплины red-green |
| `karpathy-guidelines` | `architect`, `backend`, `front`, `reviewer`; universal | всегда | правила объёма держит `beerpowers:minimal-diff` |
| `caveman` | universal | всегда | стиль отчётов ролей задаёт charter текстом |
| `caveman-review` | `reviewer` | всегда | отчёт ревью без сжатого формата строк |
| `laravel-specialist` | `backend`, `db` | стек — Laravel | роль работает по пресету `presets/laravel/` |
| `php-pro` | `backend`, `db` | стек — PHP | то же |
| `nuxt` | `front` | стек — Nuxt | роль работает по пресету `presets/nuxt/` |
| `nuxt-ui` | `front` | стоит `@nuxt/ui` | то же |

**Не зависимость:** встроенный `security-review`. При сборке промпта роли он выполняет
`git diff` от рабочего каталога, а не от репозитория задачи: в корне workspace роль либо
падает на старте (в корне нет `origin/HEAD`), либо смотрит дифф конфигурации команды вместо
кода. Security-чеклист `reviewer` и `auditor` идёт по диффу формой `git -C <репо> diff <база>`
и живёт в самих ролях.

Скилы плагина (`beerpowers:*`) в этот список не входят: они приходят с плагином, и роли
ссылаются на них по имени без записи во frontmatter.
