# /beerpowers:tracker — запись в трекер

```
/beerpowers:tracker <что сделать>
```

`<что сделать>` — словами, как в чате: «заведи баг: на мобильной шторке фильтр откатывает
выбор», «напиши в SHOP-449, что ветка отправлена», «поправь описание SHOP-448: …»,
«переведи SHOP-447 в работу», «свяжи SHOP-448 и SHOP-449», «поправь мой последний комментарий
в SHOP-449: …», «удали комментарий про ветку в SHOP-449». Без аргумента — спроси одним
вопросом, что сделать.

Команда — вход, а не второй свод правил: правила записи — `.claude/team-lead.md`, раздел
«Запись в трекер», текст задачи, бага и комментария — скил `beerpowers:tracker-task`. Прочитай
раздел, если в этой сессии ещё не читал, и иди по нему.

1. **Скил.** Загрузи `beerpowers:tracker-task` до любой записи, включая комментарий и его
   правку, если в этой сессии он ещё не загружен. Подпись не пиши по образцу из `--help`
   адаптера: её ставит адаптер по модели сессии, а не узнав модель — откажет и назовёт форму.
2. **Адаптер.** В `.claude/bin/` — скрипт записи `<трекер>-write.mjs` (контракт —
   [`workspace.md`](../reference/workspace.md), «Адаптер записи в трекер»). Нет ни одного — скажи,
   что записи в трекер в проекте нет, и чем её включить: `/beerpowers:update`, если скрипт чтения
   трекера в `.claude/bin/` есть, иначе `/beerpowers:setup`, вопрос Q5. Их несколько — спроси, в какой
   трекер.
3. **Действие** — по тексту аргумента, одно из таблицы раздела «Запись в трекер». Действий
   несколько («заведи задачу и свяжи с SHOP-449») — по очереди, в названном порядке. Неясно, что
   именно сделать, — один вопрос, а не догадка.
4. **Задача или баг.** Тип назван — по нему; нет — спроси. Очередь и доска — из названного,
   из соседних задач этого разговора или из `memory/`; нигде нет — спроси. Перед черновиком
   прочитай задачи, на которые текст ссылается, скриптом чтения трекера: зависимость
   и связи берутся из них, а не по памяти.
5. **Комментарий по id.** Правка и удаление — по id из `comments <КОД>`: комментарий
   называет человек словами, id подбираешь по автору и первой строке; подходит несколько —
   спроси. Удаление — автор и полный текст из `comments <КОД> <id>` в чате, затем «да».
6. **Дальше — по разделу «Запись в трекер»:** черновик через `check` адаптера, ссылка на файл,
   правки словами, «да», отправка; комментарий, его правка и связь — сразу. Ответ заканчивается
   ссылкой на задачу.
