# Ссылки на файлы в ответе человеку

Файл внутри рабочего каталога — кликабельной markdown-ссылкой с путём от корня рабочего
каталога, а не голым именем; место в файле — суффиксом `:строка` в адресе ссылки
(`app/файл.php:42`). Голое имя заставляет человека искать файл руками.
Исключение — таблица, где ссылка ломает колонку.

Файл вне рабочего каталога ссылкой не открывается ни в какой форме: просмотрщик клиента
не пускает за пределы каталога. Его путь пишется в обратных кавычках (`~/.claude/CLAUDE.md`);
если человеку надо файл посмотреть — он отдаётся карточкой через `SendUserFile`, и то когда файл
и есть предмет разговора, а не на каждое упоминание.

Путь Windows с обратными слэшами — только в обратных кавычках: в тексте markdown `\.`
читается как экранирование, и скрытый каталог молча теряет разделитель.
