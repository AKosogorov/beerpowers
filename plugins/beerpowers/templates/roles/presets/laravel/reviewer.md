## Слот `STACK_CHECKLISTS`

### Границы и архитектура (главный класс рисков)

```
[ ] Модуль не импортирует другой модуль напрямую — только через Application Services
[ ] Контроллер зовёт Application Service, а не доменный сервис модуля
[ ] Внешние системы (S3, поиск, почта) — за интерфейсом в app/Infrastructure
```

### Деньги — Laravel

```
[ ] Денежные значения — VARCHAR + каст денег проекта; ни float, ни decimal нигде
```

### PHP

```
[ ] declare(strict_types=1) в каждом новом файле; полные тайпхинты
[ ] PHPStan уровня <уровень> не понижен, baseline не расширен без решения пользователя
[ ] Вход валидируется Request-классом; сырой body в сервис не уходит
[ ] Секреты не в коде, логах и коммитах; .env.example актуален
[ ] final там, где наследование не нужно
```

### База данных — Laravel

```
[ ] Миграции — анонимные классы
```
