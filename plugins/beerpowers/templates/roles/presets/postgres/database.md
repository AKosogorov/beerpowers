# Пресет: PostgreSQL → db

> Фрагменты для слотов `templates/roles/database-agent.md`, когда основная БД проекта —
> PostgreSQL. Строки про схемы по модулям — только если проект раскладывает таблицы
> по схемам Postgres (`<модуль>.*`), список схем — по проекту. Форма вызова `psql` —
> из `memory/commands/<скоуп>.md`.

## Слот `ROLE_SCOPE`

- **Схемы и таблицы** — по модулям: схема на модуль (список — `memory/project/project-map.md`).
  Новая таблица попадает в схему своего модуля, а не в `public`.

## Слот `SCHEMA_CONVENTIONS`

- Гибкие данные — JSONB + индекс, если по ним ищут.

## Слот `QUERY_PLAN`

Гоняй `EXPLAIN ANALYZE` через `psql` в контейнере.

Красные флаги: `Seq Scan` по большой таблице (нет индекса), много отброшенных фильтром строк
(плохая селективность → composite/partial), `Nested Loop` с тысячами итераций (индекс на FK).
