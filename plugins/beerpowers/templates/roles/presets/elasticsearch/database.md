# Пресет: Elasticsearch → db

> Фрагменты для слотов `templates/roles/database-agent.md`, когда поиск проекта идёт
> через Elasticsearch поверх основной БД. Если описание маппинга живёт в одном классе,
> который зовут и миграция, и команда переиндексации, — назови его в проектной части роли.

## Слот `ROLE_SCOPE`

- **Индексы Elasticsearch** — маппинг меняется миграцией, переиндексация — явной командой.

## Слот `SCHEMA_CONVENTIONS`

- Elasticsearch — производный индекс, не источник правды. Расхождение с основной БД чинится
  переиндексацией, а не правкой в Elastic.
