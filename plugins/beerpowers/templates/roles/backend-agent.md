<!-- beerpowers:engine process -->

## Checklist перед завершением

<!-- beerpowers:engine checklist -->
- [ ] Модуль не зависит от модуля; координация — через слой приложения
- [ ] Вход валидируется на границе; сырой body в сервис не уходит
- [ ] Секретов в коде и логах нет; пример env-файла актуален
- [ ] Объём проверен по `beerpowers:minimal-diff`: без слоёв поверх штатных средств фреймворка
      и без зависимостей ради одного вызова
- [ ] Перенёс или удалил код — поиском по коду, тестам, миграциям, шаблонам и маршрутам
      проверено, что не осталось осиротевших методов, связей и импортов
- [ ] Изменился контракт API — описание контракта обновлено, `front` уведомлён
- [ ] Линт — charter, «Линт в конце задачи»
<!-- /beerpowers:engine -->
