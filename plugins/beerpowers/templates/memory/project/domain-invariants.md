# Доменные инварианты

Единственный список инвариантов домена: каждая роль читает его на старте, charter на него
указывает. Нарушение любого — блокер на ревью. Инвариант — заголовком с номером, под ним:
где держится кодом, где только соглашением и где код его уже нарушает, с местом в коде.
Запрет, который инвариант охраняет («сгенерированный клиент руками не правится»), — часть
инварианта здесь: ни `safety-rules.md`, ни «Не трогает» и чеклисты ролей его не повторяют.
