# Известные грабли

Не список задач и не приговор коду — список мест, где неосторожная правка стоит дорого.
Каждый пункт подтверждён чтением кода. Чинить их **по своей инициативе не надо**: часть
неочевидна, часть намеренна. Наткнулся — скажи пользователю.

Записи разложены по областям. Этот файл — индекс: что где лежит и по какому признаку запись
попадает в файл.

## Файлы `memory/issues/`

| Файл | Что внутри | Признак записи |
|---|---|---|
| `accepted-risks.md` | принятые риски и осознанные отступления — решения человека с кодом задачи и датой | следующий исполнитель не должен «починить» это как дефект |

## Ведение

- Раздела-свалки нет: запись ложится в файл своей области по таблице выше.
- Новый файл области — при трёх записях; до того запись лежит в ближайшей области.
- Одна проблема — один `###`; `##` — только подгруппы.
- Имя `known-issues.md` остаётся за индексом, записи сюда не пишутся.
