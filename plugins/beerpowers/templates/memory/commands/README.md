# Команды

Все пути — от корня workspace. Правила формы вызова — «без `cd`», литеральные пути
аллоулищенных скриптов, чтение инструментами, а не через `Bash`, — в charter, раздел
«Shell-вызовы». Здесь только указатели: роль читает свой файл, а не все сразу.

Разделы файла скоупа — «Гейты» (точные формы проверок и критерий зелёного), «Линт» (автофикс
по изменённым файлам) и «Грабли инструментов» (инструмент врёт или падает) — заводятся
с первым фактом: раздела-заглушки нет.
