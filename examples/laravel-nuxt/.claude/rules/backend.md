# Серверный слой shop-backend

- Вход валидируется Request-классом; сырой body в сервис не уходит.
- Непубличные данные — за гардом аутентификации и проверкой прав на сервере.
- Модуль `app/Modules/<Модуль>/` не импортирует другой модуль: координация — через слой приложения.
- `declare(strict_types=1);` и полные тайпхинты в каждом новом файле.
