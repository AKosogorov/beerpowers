# Команды

Все пути — от корня workspace. Правила формы вызова — «без `cd`», литеральные пути
аллоулищенных скриптов, чтение инструментами, а не через `Bash`, — в charter, раздел
«Shell-вызовы». Здесь только указатели: роль читает свой файл, а не все сразу.

| Файл | Что внутри | Кому |
|---|---|---|
| `backend.md` | гейты, линт, миграции и грабли `projects/shop-backend` | `backend`, `db`, `tester`, `reviewer`, `devops` |
| `frontend.md` | dev-сервер, сборка с проверкой типов, линт, генерация клиента API `projects/shop-frontend` | `front`, `tester`, `reviewer`, `devops` |
| `git.md` | факты git этого workspace: откуда токен API для MR | team-lead, `reviewer`, `devops` |
| `worktrees.md` | worktree задач: заведение, порты, зависимости, тестовая база | team-lead |
| `figma.md` | фреймы макета скриптом `.claude/bin/figma-export` | team-lead, `front` |

Разделы файла скоупа — «Гейты» (точные формы проверок и критерий зелёного), «Линт» (автофикс
по изменённым файлам) и «Грабли инструментов» (инструмент врёт или падает) — заводятся
с первым фактом: раздела-заглушки нет.
