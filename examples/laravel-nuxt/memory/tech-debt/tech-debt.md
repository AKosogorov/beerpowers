# Технический долг

Отличие от `issues/`: там места, где неосторожная правка стоит дорого. Здесь — то, что надо
починить, с планом и тем, чем подтверждено.

**Пункт — отдельный файл `NNN-<slug>.md`** с frontmatter: `status`, `status_note`, `area`,
`checked` (дата последней проверки по коду). Новый пункт — следующий номер за
последним в этом списке, статус `открыт`; буквенный суффикс (`20б`) допустим только у уже
существующих. Пункт снимается, когда изменился код в ветке по умолчанию на `origin`, а не когда работу взяли.

Статусы: `открыт` · `частично` (в `status_note` — что осталось) · `под сомнением` (дефект
не подтверждён или фикс в невлитой ветке) · `закрыт` (дата или задача в `status_note`) ·
`снят` (предпосылка умерла, риск принят, дубль).

**Этот файл генерируется:** `node .claude/bin/tech-debt-index.mjs`; проверка актуальности —
тот же скрипт с `--check`. Правки руками здесь затираются.

Пунктов: 0 — открыт 0, частично 0, под сомнением 0, закрыт 0, снят 0.
